Посібник користувача MainOrginizer

MainOrginizer керує ігровими середовищами Minecraft, модами, світами, наборами ресурсів, шейдерами, профілями, файлами конфігурації та резервними копіями в одному робочому просторі.

Для чого призначена програма

Програма допомагає керувати встановленнями Prism Launcher, CurseForge, офіційного лаунчера, TLauncher і старими встановленнями; вести бібліотеку JAR-файлів модів; встановлювати світи через saves; застосовувати профілі; перевіряти середовища й скасовувати зміни; створювати та відновлювати резервні копії конфігурацій.

Безпека: Попередній перегляд і перевірка середовища лише читають дані. Закрийте Minecraft перед застосуванням профілю, встановленням ресурсів, відновленням резервних копій або зміною файлів активного середовища.

Перший запуск

Відкрийте Settings → Language selection і виберіть мову. У новому встановленні типовою є англійська. У View виберіть світлу або темну тему. Відкрийте Game environments і натисніть Refresh. Якщо середовище не знайдено, скористайтеся Add game folder, Choose Prism folder або створіть екземпляр для офіційного лаунчера.

Ігрові середовища

Таблиця показує джерело, назву середовища, версію Minecraft, завантажувач, його версію та стан. Prism використовує налаштований каталог. CurseForge використовує %USERPROFILE%\curseforge\minecraft\Instances. У старих встановленнях версію та завантажувач можна визначити з назви папки або метаданих JSON. Оновлюйте список після зовнішніх змін.

Бібліотека модів

Натисніть Import JAR і виберіть файли модів; оригінали копіюються до бібліотеки. Фільтруйте за версією Minecraft, завантажувачем або сумісністю. Контекстне меню дає змогу переглянути, видалити або призначити мод профілю, якщо це підтримується. Після зовнішніх змін натисніть Refresh library.

Визначення версії

Спочатку використовуються метадані мода. Якщо вони неповні, програма також аналізує назву файла, наприклад mc1.20.1, 1.20.1-forge, dynamiclights-1.20.1.2 або +1.20.1. Мод, що підтримує кілька версій Minecraft, відображається одним записом із кількома сумісними версіями.

Ручне перевизначення версії Minecraft

Виберіть мод і скористайтеся Edit Minecraft version…. Введіть одну версію, наприклад 1.20.1, або кілька через кому, наприклад 1.20.1, 1.21. Також приймаються діапазони на кшталт [1.20,1.21). Порожнє поле скасовує перевизначення. Воно зберігається для цього файла й не змінює сам JAR.

Світи

Вкладка Saves керує світами вибраного середовища. Виберіть середовище або профіль, імпортуйте архів чи папку світу та встановіть його. MainOrginizer розміщує світ у saves. Зробіть резервну копію важливих світів перед заміною однойменного збереження.

Профілі

Профіль — це іменований набір модів і ресурсів для одного середовища. Виберіть Instance for new profile, натисніть Create profile та введіть назву. За допомогою Edit mods виберіть сумісні моди. Rename і Delete profile дають змогу керувати списком.

Застосування профілю

Виберіть профіль у розділі віртуалізації, натисніть Preview і перевірте всі дії. Застосовуйте Apply profile лише після перевірки. Rollback last application скасовує останню керовану зміну. Check conflicts допомагає виявити ручні зміни. Сторонні звичайні файли не перезаписуються.

Перевірка середовища

Вкладка показує знайдені файли Minecraft, дані завантажувача, зовнішні моди й сумісність. Вона не змінює середовище та допомагає діагностувати проблеми.

Набори ресурсів і шейдери

Виберіть Resource packs або Shaders і імпортуйте архіви через Import ZIP. Використовуйте Choose for profile, щоб додати ресурс до профілю. Preview, Apply assets і Rollback assets працюють так само, як віртуалізація профілю. Посилання створюються в resourcepacks або shaderpacks; наявні звичайні файли не перезаписуються.

Конфігурації та резервні копії

Backup створює архів із часовою позначкою для папки config вибраного середовища. Якщо папки немає, програма повідомить про це. Для відновлення виберіть архів і натисніть Restore; спочатку закрийте Minecraft. Оновіть таблицю після зовнішніх змін.

Рекомендований порядок роботи

Оновіть і перевірте середовище, імпортуйте моди й ресурси, створіть профіль, виберіть сумісний вміст і перегляньте заплановані зміни. Перед значними змінами створіть резервну копію конфігурації. Закрийте Minecraft, застосуйте профіль і перевірте гру. У разі проблем скористайтеся Rollback або Restore.

Усунення несправностей та обмеження

Якщо середовище відсутнє, оновіть список або додайте папку вручну. Якщо версія мода не визначена, перевірте метадані й назву файла. Якщо мод відфільтровано, перевірте версію Minecraft і завантажувач. Якщо застосування не вдається, закрийте Minecraft і перевірте попередній перегляд, конфлікти та права запису. MainOrginizer не встановлює завантажувачі, не завантажує моди з онлайн-сервісів і не гарантує сумісність сторонніх модів. Зберігайте окремі резервні копії важливих світів і конфігурацій.
