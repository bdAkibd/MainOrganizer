Manuale utente di MainOrginizer

MainOrginizer gestisce ambienti Minecraft, mod, mondi salvati, pacchetti di risorse, shader, profili, file di configurazione e backup in un unico spazio di lavoro.

A cosa serve il programma

Permette di gestire installazioni di Prism Launcher, CurseForge, launcher ufficiale, TLauncher e installazioni precedenti; mantenere una libreria di file JAR delle mod; installare mondi tramite saves; applicare profili; controllare gli ambienti e annullare modifiche; creare e ripristinare backup delle configurazioni.

Sicurezza: L’anteprima e i controlli dell’ambiente sono di sola lettura. Chiudi Minecraft prima di applicare profili, installare risorse, ripristinare backup o modificare file in un ambiente attivo.

Primo avvio

Apri Settings → Language selection e scegli la lingua. Nelle nuove installazioni l’inglese è predefinito. Scegli un tema chiaro o scuro da View. Apri Game environments e premi Refresh. Se un’installazione non viene rilevata, usa Add game folder, Choose Prism folder o crea un’istanza per il launcher ufficiale.

Ambienti di gioco

La tabella mostra origine, nome dell’ambiente, versione di Minecraft, loader, versione del loader e stato. Prism usa la directory configurata. CurseForge usa %USERPROFILE%\curseforge\minecraft\Instances. Nelle installazioni precedenti, versione e loader possono essere ricavati dal nome della cartella o dai metadati JSON. Aggiorna l’elenco dopo modifiche esterne.

Libreria mod

Premi Import JAR e seleziona i file; gli originali vengono copiati nella libreria. Filtra per versione di Minecraft, loader o compatibilità. Il menu contestuale consente di esaminare, rimuovere o assegnare una mod a un profilo, se supportato. Premi Refresh library dopo modifiche esterne.

Rilevamento versione

Il programma usa prima i metadati della mod. Se sono incompleti, esamina anche il nome del file, ad esempio mc1.20.1, 1.20.1-forge, dynamiclights-1.20.1.2 o +1.20.1. Una mod che supporta più versioni di Minecraft rimane una sola voce con più versioni compatibili.

Override manuale della versione Minecraft

Seleziona la mod e usa Edit Minecraft version…. Inserisci una versione, ad esempio 1.20.1, o più versioni separate da virgole, ad esempio 1.20.1, 1.21. Sono accettati anche intervalli come [1.20,1.21). Lascia il campo vuoto per rimuovere l’override. L’impostazione è salvata per quel file e non modifica il JAR.

Mondi salvati

La scheda Saves gestisce i mondi dell’ambiente selezionato. Scegli un ambiente o profilo, importa un archivio o una cartella del mondo e installalo. MainOrginizer lo inserisce in saves. Esegui il backup dei mondi importanti prima di sostituire un salvataggio con lo stesso nome.

Profili

Un profilo è una selezione nominata di mod e risorse per un ambiente. Scegli Instance for new profile, premi Create profile e inserisci un nome. Usa Edit mods per selezionare mod compatibili. Rename e Delete profile gestiscono l’elenco.

Applicare un profilo

Seleziona il profilo nella sezione di virtualizzazione, premi Preview e controlla tutte le azioni. Usa Apply profile solo dopo aver verificato l’anteprima. Rollback last application annulla l’ultima modifica gestita. Check conflicts aiuta se i file sono stati modificati manualmente. I file normali non correlati non vengono sovrascritti.

Controllo dell’ambiente

La scheda mostra file Minecraft rilevati, informazioni sul loader, mod esterne e dettagli di compatibilità. Non modifica l’ambiente ed è utile per diagnosticare problemi.

Pacchetti di risorse e shader

Scegli Resource packs o Shaders e importa archivi con Import ZIP. Usa Choose for profile per includere una risorsa nel profilo. Preview, Apply assets e Rollback assets funzionano come la virtualizzazione dei profili. I collegamenti vengono creati in resourcepacks o shaderpacks senza sovrascrivere file normali esistenti.

Configurazioni e backup

Backup crea un archivio con data e ora della cartella config dell’ambiente selezionato. Se la cartella manca, il programma lo segnala. Per ripristinare, seleziona un backup e usa Restore; prima chiudi Minecraft. Aggiorna la tabella dopo modifiche esterne.

Procedura consigliata

Aggiorna e verifica l’ambiente, importa mod e risorse, crea un profilo, scegli contenuti compatibili e controlla l’anteprima. Esegui il backup della configurazione prima di modifiche importanti. Chiudi Minecraft, applica il profilo e prova il gioco. In caso di problemi, usa Rollback o Restore.

Risoluzione dei problemi e limiti

Se manca un ambiente, aggiorna l’elenco o aggiungi manualmente la cartella del gioco. Se una mod non ha versione, controlla metadati e nome del file. Se viene filtrata, controlla versione di Minecraft e loader. Se l’applicazione fallisce, chiudi Minecraft e controlla anteprima, conflitti e permessi di scrittura. MainOrginizer non installa loader, non scarica mod online e non garantisce la compatibilità di mod di terze parti. Conserva backup indipendenti di mondi e configurazioni importanti.
