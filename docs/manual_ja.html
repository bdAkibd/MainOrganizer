MainOrginizer ユーザーマニュアル

MainOrginizer は Minecraft のゲーム環境、Mod、ワールド保存データ、リソースパック、シェーダー、プロファイル、設定ファイル、バックアップを一つの作業スペースで管理するデスクトップアプリです。

このプログラムについて

Prism Launcher、CurseForge、公式ランチャー、TLauncher、旧式のインストール環境を管理し、Mod の JAR ライブラリを整理し、saves フォルダー経由でワールドをインストールし、プロファイルを適用し、環境の確認や変更の取り消し、設定のバックアップと復元を行えます。

安全上の注意: プレビューと環境チェックは読み取り専用です。プロファイルの適用、アセットのインストール、バックアップの復元、使用中の環境のファイル変更を行う前に Minecraft を終了してください。

初回起動

Settings → Language selection を開いて言語を選択します。新規インストールでは英語が既定です。View でライトまたはダークテーマを選びます。Game environments を開いて Refresh を押してください。環境が見つからない場合は Add game folder、Choose Prism folder、または公式ランチャー用インスタンスの作成を使用します。

ゲーム環境

表にはソース、環境名、Minecraft のバージョン、ローダーとそのバージョン、状態が表示されます。Prism は設定済みの Prism ディレクトリを使用します。CurseForge の場所は %USERPROFILE%\curseforge\minecraft\Instances です。旧式の環境ではフォルダー名や JSON メタデータから情報を取得する場合があります。外部で変更した後は一覧を更新してください。

Mod ライブラリ

Import JAR を押して Mod ファイルを選択すると、元のファイルがライブラリにコピーされます。Minecraft バージョン、ローダー、互換性で絞り込めます。コンテキストメニューから詳細確認、削除、対応している場合はプロファイルへの割り当てができます。外部で変更した後は Refresh library を押します。

バージョン検出

まず Mod のメタデータを使用します。不完全な場合は mc1.20.1、1.20.1-forge、dynamiclights-1.20.1.2、+1.20.1 などのファイル名も調べます。複数の Minecraft バージョンに対応する Mod は、互換バージョンを複数持つ一つの項目として扱われます。

Minecraft バージョンの手動指定

Mod を選択して Edit Minecraft version… を使用します。1.20.1 のような単一バージョン、または 1.20.1, 1.21 のようにカンマ区切りの複数バージョンを入力できます。[1.20,1.21) のような範囲も使用できます。空欄にすると手動指定が解除されます。この設定は対象ファイルに保存され、JAR 自体は変更しません。

ワールド保存データ

Saves タブでは選択した環境のワールドを管理します。環境またはプロファイルを選び、ワールドのアーカイブやフォルダーをライブラリにインポートしてインストールします。MainOrginizer は saves フォルダーに配置します。同名の保存データを置き換える前に大切なワールドをバックアップしてください。

プロファイル

プロファイルは、ゲーム環境向けの Mod と関連アセットの名前付きセットです。Instance for new profile で環境を選び、Create profile で名前を設定します。Edit mods で互換性のある Mod を選択します。Rename と Delete profile で一覧を管理します。

プロファイルの適用

仮想化セクションでプロファイルを選び、Preview で各操作を確認します。内容に問題がない場合のみ Apply profile を使用してください。Rollback last application は直近の管理対象変更を取り消します。手動でファイルを変更した場合は Check conflicts を使います。関係のない通常ファイルは上書きされません。

環境の確認

このタブでは検出された Minecraft ファイル、ローダー情報、外部 Mod、互換性を確認できます。環境を変更せず、問題の診断に役立ちます。

リソースパックとシェーダー

Resource packs または Shaders を選び、Import ZIP でアーカイブを取り込みます。Choose for profile でプロファイルに追加できます。Preview、Apply assets、Rollback assets はプロファイルの仮想化と同様に使用します。リンクは resourcepacks または shaderpacks に作成され、既存の通常ファイルは上書きされません。

設定とバックアップ

Backup は選択した環境の config フォルダーを日時付きアーカイブにします。フォルダーがない場合は通知します。復元するにはバックアップを選択して Restore を使います。先に Minecraft を終了してください。外部でアーカイブを変更した後は一覧を更新します。

推奨される手順

対象環境を更新して確認し、Mod とリソースをインポートしてプロファイルを作成します。互換性のある内容を選び、変更プレビューを確認してください。大きな変更の前に設定をバックアップします。Minecraft を終了してプロファイルを適用し、ゲームを起動してテストします。問題があれば Rollback または Restore を使用します。

トラブルシューティングと制限

環境がない場合は一覧を更新するかゲームフォルダーを手動で追加します。Mod のバージョンが不明な場合はメタデータとファイル名を確認します。フィルターで非表示の場合は Minecraft のバージョンとローダーを確認します。適用に失敗した場合は Minecraft を終了し、プレビュー、競合、書き込み権限を確認します。MainOrginizer はローダーのインストールやオンラインからの Mod ダウンロードを行わず、第三者 Mod の互換性も保証しません。重要なワールドと設定は別途バックアップしてください。
