MainOrginizer 用户手册

MainOrginizer 是一款桌面工具，用于集中管理 Minecraft 游戏环境、模组、存档、资源包、光影、配置档案、配置文件和备份，帮助你安全切换整套内容。

程序用途

可用于管理 Prism Launcher、CurseForge、官方启动器、TLauncher 和旧版安装环境；维护可搜索的模组 JAR 库；通过 saves 文件夹安装世界；应用配置档案；检查环境并撤销托管更改；备份和恢复配置文件。

安全提示: 预览和环境检查均为只读操作。应用配置档案、安装资源、恢复备份或修改正在使用的环境文件前，请先关闭 Minecraft。

首次启动

打开 Settings → Language selection 选择界面语言。新安装默认使用英语。可在 View 中选择浅色或深色主题。打开 Game environments 并点击 Refresh。若未检测到安装环境，请使用 Add game folder、Choose Prism folder，或为官方启动器创建实例。

游戏环境

表格显示来源、环境名称、Minecraft 版本、加载器、加载器版本和状态。Prism 使用已配置的 Prism 目录。CurseForge 使用 %USERPROFILE%\curseforge\minecraft\Instances。旧版安装可能从文件夹名称或 JSON 元数据读取版本和加载器信息。外部安装或删除实例后请刷新列表。

模组库

点击 Import JAR 并选择一个或多个模组文件，原文件会复制到模组库。可按 Minecraft 版本、加载器或兼容性筛选。右键菜单可查看详情、从库中移除，或在支持时分配给配置档案。在程序外更改库文件后，点击 Refresh library。

版本检测

程序优先读取模组元数据。元数据不完整时，也会检查文件名，例如 mc1.20.1、1.20.1-forge、dynamiclights-1.20.1.2 和 +1.20.1。支持多个 Minecraft 版本的模组会作为一个条目显示，并包含多个兼容版本，不会因选择配置档案版本而重复出现。

手动指定 Minecraft 版本

选择模组并使用 Edit Minecraft version…。可输入单个版本（如 1.20.1），也可输入逗号分隔的多个版本（如 1.20.1, 1.21）。也接受 [1.20,1.21) 这样的版本范围。清空字段可取消手动指定。设置会针对该文件保存，不会修改 JAR 文件本身。

存档

Saves 标签页管理所选环境的 Minecraft 世界。选择环境或配置档案，将世界压缩包或文件夹导入存档库并安装。MainOrginizer 会将其放入 saves 目录。替换同名存档前，请备份重要世界。

配置档案

配置档案是针对某个游戏环境命名保存的一组模组和相关资源。通过 Instance for new profile 选择目标环境，点击 Create profile 并输入名称。使用 Edit mods 选择兼容模组。通过 Rename 或 Delete profile 管理列表。

应用配置档案

在虚拟化区域选择配置档案，点击 Preview 并检查每项操作。确认预览无误后再点击 Apply profile。Rollback last application 可撤销最近一次托管更改。若目标文件夹中有手动修改，使用 Check conflicts。程序不会覆盖无关的普通文件。

环境检查

此标签页报告检测到的 Minecraft 文件、加载器信息、外部模组和兼容性详情。检查不会修改环境，可用于诊断模组不可用等问题。

资源包与光影

选择 Resource packs 或 Shaders，使用 Import ZIP 将压缩包复制到独立资源库。使用 Choose for profile 将资源加入配置档案。Preview、Apply assets 和 Rollback assets 的用法与配置档案虚拟化相同。资源会链接到 resourcepacks 或 shaderpacks 文件夹，不会覆盖已有普通文件。

配置与备份

Backup 会将所选环境的 config 文件夹打包并添加时间戳。如果不存在该文件夹，程序会提示且不会创建误导性备份。选择已有备份并使用 Restore 可恢复配置；请先关闭 Minecraft。在程序外添加或删除压缩包后刷新列表。

推荐流程

刷新并确认目标环境；将模组、存档、资源包和光影导入各自的库；创建配置档案；选择兼容内容并预览更改；重大修改前备份配置；关闭 Minecraft 后应用配置档案并测试游戏。如有问题，关闭游戏并使用 Rollback 或 Restore。

故障排除与限制

环境缺失时刷新列表或手动添加游戏目录。模组没有版本时检查元数据和文件名。模组被筛选隐藏时检查 Minecraft 版本和加载器。应用失败时关闭 Minecraft，检查预览、冲突和目标文件夹写入权限。MainOrginizer 不安装 Minecraft 加载器、不从在线服务下载模组，也不保证第三方模组兼容。请单独备份重要世界和配置。
