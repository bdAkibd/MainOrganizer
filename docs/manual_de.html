MineOrganizer – Benutzerhandbuch

MineOrganizer verwaltet Minecraft-Spielumgebungen, Mods, Spielstände, Ressourcenpakete, Shader, Profile, Konfigurationsdateien und Sicherungen in einem gemeinsamen Arbeitsbereich.

Wofür das Programm gedacht ist

Nutzen Sie das Programm, um Installationen von Prism Launcher, CurseForge, dem offiziellen Launcher, TLauncher und älteren Installationen zu verwalten; eine durchsuchbare Mod-JAR-Bibliothek zu führen; Welten über den Ordner saves zu installieren; Profile anzuwenden; Umgebungen zu prüfen und Änderungen zurückzusetzen; sowie Konfigurationen zu sichern und wiederherzustellen.

Sicherheit: Vorschau und Umgebungsprüfungen lesen Daten nur aus. Schließen Sie Minecraft, bevor Sie Profile anwenden, Ressourcen installieren, Sicherungen wiederherstellen oder Dateien einer aktiven Umgebung ändern.

Erster Start

Öffnen Sie Settings → Language selection und wählen Sie die Sprache. Bei einer Neuinstallation ist Englisch voreingestellt. Wählen Sie unter View ein helles oder dunkles Design. Öffnen Sie Game environments und klicken Sie auf Refresh. Falls eine Installation fehlt, verwenden Sie Add game folder, Choose Prism folder oder erstellen Sie eine Instanz für den offiziellen Launcher.

Spielumgebungen

Die Tabelle zeigt Quelle, Umgebungsname, Minecraft-Version, Loader, Loader-Version und Status. Prism-Instanzen werden aus dem konfigurierten Prism-Verzeichnis gelesen. CurseForge-Instanzen befinden sich unter %USERPROFILE%\curseforge\minecraft\Instances. Bei Legacy-Installationen können Versions- und Loader-Informationen aus Ordnernamen oder JSON-Metadaten stammen. Aktualisieren Sie die Liste nach externen Änderungen.

Mod-Bibliothek

Klicken Sie auf Import JAR und wählen Sie Mod-Dateien aus; die Originale werden in die Bibliothek kopiert. Filtern Sie nach Minecraft-Version, Loader oder Kompatibilität. Über das Kontextmenü können Sie Details ansehen, Dateien entfernen oder sie einem Profil zuweisen. Verwenden Sie nach externen Änderungen Refresh library.

Versionserkennung

Die Version wird zuerst anhand der Mod-Metadaten erkannt. Bei unvollständigen Metadaten untersucht das Programm auch Dateinamen, etwa mc1.20.1, 1.20.1-forge, dynamiclights-1.20.1.2 oder +1.20.1. Unterstützt eine Mod mehrere Minecraft-Versionen, bleibt sie ein einzelner Eintrag mit mehreren kompatiblen Versionen.

Minecraft-Version manuell überschreiben

Wählen Sie eine Mod aus und verwenden Sie Edit Minecraft version…. Geben Sie eine Version wie 1.20.1 oder mehrere durch Kommas getrennte Versionen wie 1.20.1, 1.21 ein. Bereiche wie [1.20,1.21) werden ebenfalls akzeptiert. Ein leeres Feld entfernt die Überschreibung. Sie wird für genau diese Datei gespeichert und verändert die JAR-Datei nicht.

Spielstände

Im Tab Saves verwalten Sie Welten der ausgewählten Umgebung. Wählen Sie eine Umgebung oder ein Profil, importieren Sie ein Weltarchiv oder einen Weltordner und installieren Sie die Welt. MineOrganizer legt sie im Ordner saves ab. Sichern Sie wichtige Welten, bevor Sie einen gleichnamigen Spielstand ersetzen.

Profile

Ein Profil ist eine benannte Auswahl von Mods und Ressourcen für eine Spielumgebung. Wählen Sie Instance for new profile, klicken Sie auf Create profile und geben Sie einen Namen ein. Mit Edit mods wählen Sie kompatible Mods aus. Rename und Delete profile verwalten die Liste.

Profil anwenden

Wählen Sie das Profil im Virtualisierungsbereich, klicken Sie auf Preview und prüfen Sie alle Aktionen. Verwenden Sie Apply profile erst nach erfolgreicher Prüfung. Rollback last application macht die letzte verwaltete Änderung rückgängig. Check conflicts hilft bei manuell geänderten Dateien. Nicht zugehörige reguläre Dateien werden nicht überschrieben.

Umgebungsprüfung

Die Prüfung meldet erkannte Minecraft-Dateien, Loader-Informationen, externe Mods und Kompatibilitätsdetails. Sie verändert die Umgebung nicht und hilft bei der Fehlersuche.

Ressourcenpakete und Shader

Wählen Sie Resource packs oder Shaders und importieren Sie Archive mit Import ZIP. Mit Choose for profile nehmen Sie Ressourcen in ein Profil auf. Verwenden Sie Preview, Apply assets und Rollback assets. Verknüpfungen werden in resourcepacks oder shaderpacks angelegt; vorhandene reguläre Dateien bleiben erhalten.

Konfigurationen und Sicherungen

Backup erstellt ein Archiv des Ordners config der ausgewählten Umgebung. Fehlt der Ordner, meldet das Programm dies. Wählen Sie zum Wiederherstellen ein Archiv und verwenden Sie Restore; schließen Sie Minecraft vorher. Aktualisieren Sie die Tabelle nach externen Änderungen.

Empfohlener Ablauf

Aktualisieren und prüfen Sie die Zielumgebung, importieren Sie Mods und Ressourcen, erstellen Sie ein Profil, wählen Sie kompatible Inhalte und prüfen Sie die Vorschau. Sichern Sie vor größeren Änderungen die Konfiguration. Schließen Sie Minecraft, wenden Sie das Profil an und testen Sie das Spiel. Bei Problemen verwenden Sie Rollback oder Restore.

Fehlerbehebung und Grenzen

Fehlt eine Umgebung, aktualisieren Sie die Liste oder fügen Sie den Spielordner manuell hinzu. Fehlt einer Mod die Version, prüfen Sie Metadaten und Dateinamen. Wird eine Mod gefiltert, prüfen Sie Minecraft-Version und Loader. Schlägt die Anwendung fehl, schließen Sie Minecraft und prüfen Sie Vorschau, Konflikte und Schreibrechte. MineOrganizer installiert keine Loader, lädt keine Mods aus Onlinediensten herunter und garantiert keine Kompatibilität von Drittanbieter-Mods. Bewahren Sie unabhängige Sicherungen wichtiger Welten und Konfigurationen auf.
