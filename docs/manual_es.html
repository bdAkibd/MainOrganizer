Manual de usuario de MainOrginizer

MainOrginizer gestiona entornos de Minecraft, mods, mundos guardados, paquetes de recursos, shaders, perfiles, archivos de configuración y copias de seguridad en un espacio de trabajo común.

Para qué sirve

Permite gestionar instalaciones de Prism Launcher, CurseForge, el lanzador oficial, TLauncher e instalaciones antiguas; mantener una biblioteca de archivos JAR de mods; instalar mundos mediante saves; aplicar perfiles; comprobar entornos y revertir cambios; y guardar o restaurar configuraciones.

Seguridad: La vista previa y las comprobaciones solo leen datos. Cierra Minecraft antes de aplicar perfiles, instalar recursos, restaurar copias de seguridad o modificar archivos de un entorno activo.

Primer inicio

Abre Settings → Language selection y elige el idioma. En una instalación nueva, el inglés es el predeterminado. Elige un tema claro u oscuro en View. Abre Game environments y pulsa Refresh. Si no se detecta una instalación, usa Add game folder, Choose Prism folder o crea una instancia para el lanzador oficial.

Entornos de juego

La tabla muestra el origen, nombre del entorno, versión de Minecraft, cargador, versión del cargador y estado. Prism usa su directorio configurado. CurseForge usa %USERPROFILE%\curseforge\minecraft\Instances. En instalaciones antiguas, la versión y el cargador pueden obtenerse del nombre de la carpeta o de metadatos JSON. Actualiza la lista después de realizar cambios externos.

Biblioteca de mods

Pulsa Import JAR y selecciona archivos; los originales se copian en la biblioteca. Filtra por versión de Minecraft, cargador o compatibilidad. El menú contextual permite consultar, quitar o asignar un mod a un perfil cuando sea compatible. Pulsa Refresh library después de cambiar archivos fuera del programa.

Detección de versiones

Primero se usan los metadatos del mod. Si están incompletos, también se examina el nombre del archivo, por ejemplo mc1.20.1, 1.20.1-forge, dynamiclights-1.20.1.2 o +1.20.1. Un mod compatible con varias versiones aparece como una sola entrada con varias versiones compatibles.

Cambiar manualmente la versión de Minecraft

Selecciona el mod y usa Edit Minecraft version…. Introduce una versión como 1.20.1 o varias separadas por comas, como 1.20.1, 1.21. También se aceptan rangos como [1.20,1.21). Deja el campo vacío para borrar la sobrescritura. Se guarda para ese archivo y no modifica el JAR.

Mundos guardados

La pestaña Saves gestiona mundos del entorno seleccionado. Elige un entorno o perfil, importa un archivo comprimido o carpeta de mundo e instálalo. MainOrginizer lo coloca en saves. Haz una copia de seguridad de los mundos importantes antes de reemplazar un guardado con el mismo nombre.

Perfiles

Un perfil es una selección con nombre de mods y recursos para un entorno. Elige Instance for new profile, pulsa Create profile y escribe un nombre. Usa Edit mods para seleccionar mods compatibles. Rename y Delete profile permiten mantener la lista.

Aplicar un perfil

Selecciona el perfil en la sección de virtualización, pulsa Preview y revisa las acciones. Usa Apply profile solo cuando la vista previa sea correcta. Rollback last application deshace el último cambio gestionado. Check conflicts ayuda si se han cambiado archivos manualmente. No se sobrescriben archivos normales ajenos al perfil.

Comprobación del entorno

La pestaña informa de archivos de Minecraft detectados, cargadores, mods externos y compatibilidad. No modifica el entorno y resulta útil para diagnosticar problemas.

Paquetes de recursos y shaders

Selecciona Resource packs o Shaders e importa archivos con Import ZIP. Usa Choose for profile para incluir recursos en un perfil. Preview, Apply assets y Rollback assets funcionan como en la virtualización. Los enlaces se colocan en resourcepacks o shaderpacks y no sobrescriben archivos normales existentes.

Configuraciones y copias de seguridad

Backup crea un archivo con fecha y hora de la carpeta config del entorno. Si no existe, el programa lo indica. Para restaurar, selecciona una copia y usa Restore; cierra Minecraft primero. Actualiza la tabla tras añadir o eliminar archivos externos.

Flujo recomendado

Actualiza y verifica el entorno, importa mods y recursos, crea un perfil, selecciona contenido compatible y revisa la vista previa. Guarda una copia de seguridad de la configuración antes de cambios importantes. Cierra Minecraft, aplica el perfil y prueba el juego. Si hay problemas, utiliza Rollback o Restore.

Solución de problemas y límites

Si falta un entorno, actualiza o añade manualmente la carpeta del juego. Si un mod no tiene versión, revisa los metadatos y el nombre del archivo. Si queda filtrado, comprueba la versión de Minecraft y el cargador. Si falla la aplicación, cierra Minecraft y revisa la vista previa, los conflictos y los permisos de escritura. MainOrginizer no instala cargadores ni descarga mods en línea, y no garantiza la compatibilidad de mods de terceros. Conserva copias independientes de mundos y configuraciones importantes.
