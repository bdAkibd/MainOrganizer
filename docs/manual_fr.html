Manuel utilisateur de MineOrganizer

MineOrganizer gère les environnements Minecraft, les mods, les mondes sauvegardés, les packs de ressources, les shaders, les profils, les fichiers de configuration et les sauvegardes dans un espace de travail commun.

À quoi sert le programme

Il permet de gérer les installations de Prism Launcher, CurseForge, du lanceur officiel, de TLauncher et les anciennes installations ; de conserver une bibliothèque de fichiers JAR de mods ; d’installer des mondes via saves ; d’appliquer des profils ; de vérifier les environnements et d’annuler des changements ; et de sauvegarder ou restaurer les configurations.

Sécurité: L’aperçu et les vérifications ne font que lire les données. Fermez Minecraft avant d’appliquer un profil, d’installer des ressources, de restaurer une sauvegarde ou de modifier des fichiers dans un environnement actif.

Premier lancement

Ouvrez Settings → Language selection et choisissez la langue. L’anglais est utilisé par défaut lors d’une nouvelle installation. Choisissez un thème clair ou sombre dans View. Ouvrez Game environments et cliquez sur Refresh. Si une installation manque, utilisez Add game folder, Choose Prism folder ou créez une instance pour le lanceur officiel.

Environnements de jeu

Le tableau indique la source, le nom de l’environnement, la version de Minecraft, le chargeur, sa version et l’état. Prism utilise son répertoire configuré. CurseForge utilise %USERPROFILE%\curseforge\minecraft\Instances. Pour les anciennes installations, la version et le chargeur peuvent être déduits du nom du dossier ou des métadonnées JSON. Actualisez après des modifications externes.

Bibliothèque de mods

Cliquez sur Import JAR et sélectionnez des fichiers ; les originaux sont copiés dans la bibliothèque. Filtrez par version de Minecraft, chargeur ou compatibilité. Le menu contextuel permet d’examiner, de retirer ou d’affecter un mod à un profil lorsque c’est pris en charge. Cliquez sur Refresh library après des modifications externes.

Détection des versions

La détection utilise d’abord les métadonnées du mod. Si elles sont incomplètes, le nom du fichier est également examiné, par exemple mc1.20.1, 1.20.1-forge, dynamiclights-1.20.1.2 ou +1.20.1. Un mod prenant en charge plusieurs versions apparaît comme une seule entrée avec plusieurs versions compatibles.

Remplacement manuel de la version Minecraft

Sélectionnez le mod et utilisez Edit Minecraft version…. Saisissez une version comme 1.20.1 ou plusieurs versions séparées par des virgules, comme 1.20.1, 1.21. Les plages comme [1.20,1.21) sont acceptées. Laissez le champ vide pour supprimer la valeur manuelle. Elle est enregistrée pour ce fichier sans modifier le JAR.

Mondes sauvegardés

L’onglet Saves gère les mondes de l’environnement sélectionné. Choisissez un environnement ou un profil, importez une archive ou un dossier de monde et installez-le. MineOrganizer le place dans saves. Sauvegardez les mondes importants avant de remplacer une sauvegarde portant le même nom.

Profils

Un profil est une sélection nommée de mods et de ressources pour un environnement. Choisissez Instance for new profile, cliquez sur Create profile et saisissez un nom. Utilisez Edit mods pour sélectionner les mods compatibles. Rename et Delete profile permettent de gérer la liste.

Appliquer un profil

Sélectionnez le profil dans la section de virtualisation, cliquez sur Preview et examinez les actions proposées. Utilisez Apply profile seulement après vérification. Rollback last application annule la dernière modification gérée. Check conflicts aide lorsque des fichiers ont été modifiés manuellement. Les fichiers ordinaires sans rapport ne sont pas écrasés.

Vérification de l’environnement

Cet onglet signale les fichiers Minecraft détectés, les informations du chargeur, les mods externes et la compatibilité. Il ne modifie pas l’environnement et aide au diagnostic.

Packs de ressources et shaders

Sélectionnez Resource packs ou Shaders et importez des archives avec Import ZIP. Utilisez Choose for profile pour inclure une ressource dans un profil. Preview, Apply assets et Rollback assets fonctionnent comme la virtualisation des profils. Les liens sont placés dans resourcepacks ou shaderpacks sans écraser les fichiers ordinaires existants.

Configurations et sauvegardes

Backup crée une archive horodatée du dossier config de l’environnement. Si le dossier n’existe pas, le programme le signale. Pour restaurer, sélectionnez une sauvegarde et utilisez Restore ; fermez d’abord Minecraft. Actualisez le tableau après les changements externes.

Procédure recommandée

Actualisez et vérifiez l’environnement cible, importez les mods et ressources, créez un profil, choisissez le contenu compatible et vérifiez l’aperçu. Sauvegardez la configuration avant une modification importante. Fermez Minecraft, appliquez le profil et testez le jeu. En cas de problème, utilisez Rollback ou Restore.

Dépannage et limites

Si un environnement manque, actualisez ou ajoutez son dossier manuellement. Si un mod n’a pas de version, vérifiez les métadonnées et le nom du fichier. Si un mod est filtré, vérifiez la version Minecraft et le chargeur. En cas d’échec, fermez Minecraft et vérifiez l’aperçu, les conflits et les droits d’écriture. MineOrganizer n’installe pas les chargeurs, ne télécharge pas de mods en ligne et ne garantit pas la compatibilité des mods tiers. Conservez des sauvegardes indépendantes des mondes et configurations importants.
