# MineOrganizer

**Менеджер модификаций Minecraft с виртуализацией модов и управлением игровыми профилями.**

MineOrganizer — бесплатная программа с открытым исходным кодом, предназначенная для удобного управления модами Minecraft. Проект позволяет организовывать модификации в единой библиотеке, формировать игровые профили и использовать разные наборы модов без необходимости вручную копировать файлы между папками игры.

## Возможности

- **Управление модами** — хранение, сортировка и организация модификаций в общей библиотеке.
- **Игровые профили** — создание и использование разных конфигураций модов.
- **Виртуализация** — подключение модификаций к игровым окружениям с помощью файловых ссылок.
- **Поддержка игровых окружений** — обнаружение и работа с поддерживаемыми лаунчерами Minecraft.
- **Ресурсы Minecraft** — управление ресурс-паками и шейдерами.
- **Настройки и конфигурации** — работа с конфигурационными файлами и их резервными копиями.

Доступность отдельных возможностей зависит от лаунчера и конфигурации игрового окружения.

## Бесплатность и открытый код

MineOrganizer полностью бесплатен. Программа не требует покупки лицензии для личного использования.

Исходный код доступен для изучения, изменения и адаптации под собственные потребности. Вы можете дорабатывать программу, добавлять функции, исправлять ошибки и создавать собственные сборки в соответствии с условиями лицензии проекта.

## Установка

1. Перейдите в раздел [Releases](../../releases).
2. Скачайте последнюю доступную сборку.
3. Запустите файл Setup и следуйте инструкциям.
4. Запустите программу и проверьте обнаруженные игровые окружения.
5. При необходимости укажите путь к игровому каталогу вручную.

Если готовая сборка недоступна, следуйте инструкциям по запуску из исходного кода, если они предоставлены в репозитории.
