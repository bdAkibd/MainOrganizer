# MineOrganizer (MOrg)

**A Minecraft mod manager with virtualized mod libraries and game profile management.**

MineOrganizer is a free application designed to make managing Minecraft mods easier and more organized. It allows users to maintain a shared mod library, create different mod profiles, and manage game environments without manually copying mod files between folders.

## Features

- **Mod management** — organize, sort, and manage modifications in a shared library.
- **Game profiles** — create and use different configurations of mods.
- **Virtualization** — connect mods to game environments using file links.
- **Launcher support** — detect and work with supported Minecraft launchers and game environments.
- **Minecraft resources** — manage resource packs and shaders.
- **Configuration management** — work with configuration files and create backups.

The availability of individual features may depend on the launcher and game environment.
